# MacBook Website

A visually rich, Apple-style product website built with React, Three.js, GSAP, and TailwindCSS.  

## Features

- **3D Product Scenes**: Interactive product visuals powered by Three.js.
- **Scroll Animations**: Smooth transitions and effects using GSAP.
- **Pinned Sections**: Engaging sections that stay fixed during scrolling.
- **Responsive Design**: Mobile-friendly layouts with TailwindCSS.

## Tech Stack

- React – UI framework
- Three.js – 3D graphics
- GSAP – Animation library
- TailwindCSS – Utility-first CSS framework

## What’s Done

- Built core product pages and layout.
- Implemented 3D MacBook scenes.
- Added smooth scroll-based animations.
- Created pinned sections for product highlights.
- Made site responsive for different devices.
- Deployed live on Vercel.

```

```

```

```

```

```

